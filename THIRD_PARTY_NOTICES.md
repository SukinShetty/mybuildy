# Third-party notices

## Shipped with the app

Every npm package inside the app, with its licence text, is listed under "npm packages in the app" at the end (generated by `node scripts/check-licences.mjs --write-notices`; CI fails if one is missing).

### Speech embedding (wake word front end)
- What: the convolutional network of Google's `speech_embedding` (TensorFlow Hub / Kaggle Models, `google/speech-embedding`, TensorFlow 1, version 1), re-exported by us to ONNX (`resources/wake/speech-embedding.onnx`) with `scripts/wake-model/export_embedding.py`. The log-mel step in front of it is our own code (`scripts/wake-model/logmel.py`, `src/main/log-mel.ts`); the re-export matches Google's original module to within 4e-5.
- Source: https://www.kaggle.com/models/google/speech-embedding (licence stated on that page: Apache License 2.0). Originally published at https://tfhub.dev/google/speech_embedding/1.
- Licence: Apache License 2.0, https://www.apache.org/licenses/LICENSE-2.0. Copyright Google LLC. Modified: converted from a TensorFlow graph to ONNX, with the log-mel front end removed.

### Wake word classifier
- Our own small network (`resources/wake/hey-buildy.json`), trained by us on the speech-embedding outputs of the data listed under "Used for training only". No openWakeWord model files are shipped or used.

### Speech recognition (on-device, the mic button)
- whisper-tiny.en (OpenAI Whisper; code and weights released by OpenAI under the MIT licence, Copyright 2022 OpenAI; the Hugging Face model cards openai/whisper-tiny.en and onnx-community/whisper-tiny.en state Apache License 2.0) in the ONNX conversion from onnx-community/whisper-tiny.en, `resources/whisper` (fp32 encoder, 8-bit decoder).

### Text to speech (on-device)
- Kokoro-82M (hexgrad/Kokoro-82M, Apache License 2.0), ONNX conversion onnx-community/Kokoro-82M-v1.0-ONNX (Apache License 2.0), fp16 model in `resources/kokoro`. The two voices that ship, `af_bella` (female voice) and `am_puck` (male voice), are Kokoro's voice files (Apache License 2.0), in `out/voices`.
- kokoro-js 1.2.1 (Apache License 2.0, Copyright hexgrad / Xenova): loads the model and runs it. MyBuildy calls only its model and tokenizer (`generate_from_ids`); its text-to-phoneme step is not used. `src/main/kokoro-g2p.ts` contains a port of kokoro-js's `normalize_text` (Apache License 2.0), modified (two eSpeak-only rules removed, the letter-dot rule limited to capitals).
- Transformers.js (`@huggingface/transformers` 3.8.1, Apache License 2.0) and ONNX Runtime (`onnxruntime-node`, `onnxruntime-web`, `onnxruntime-common`, MIT, Copyright Microsoft Corporation) run the voice and speech-recognition models.

### Text to phonemes (pronunciation), with no eSpeak NG
- misaki (https://github.com/hexgrad/misaki, version 0.9.4, Apache License 2.0, Copyright the misaki authors): Kokoro's own English G2P. Its US pronunciation dictionaries `us_gold.json` and `us_silver.json` ship byte for byte in `out/data/` (sha256 dc414872…686f and de8f67be…ac475). The wheel does not state where the word list itself comes from.
- @titan-design/speech-g2p 0.0.0 (MIT, Copyright 2026 Henry Jewkes): a TypeScript port of misaki's English G2P. Contains spaCy 3.8.16 / en_core_web_sm 3.8.0 tokenizer rules (MIT, Copyright Explosion AI GmbH) in `out/data/spacy-en-tokenizer.json`.
- compromise 14.18.0 (MIT, Copyright Spencer Kelly) and its parts efrt, grad-school, suffix-thumb (MIT): part-of-speech tags, so misaki picks the right reading of words like "read" and "lead".
- phonemize 2.0.1 (MIT, Copyright 2025 Hans): letter-to-sound rules for words no dictionary has. Its English word list is built from ipa-dict `en_US` (MIT, Copyright 2016 dohliam), which comes from the CMU Pronouncing Dictionary (BSD-style licence, Copyright Carnegie Mellon University), plus misaki homographs (Apache License 2.0). number-to-words (MIT).

### Not shipped
- eSpeak NG (GPL-3.0-or-later) and the `phonemizer` npm package that contains it (kokoro-js imports it): replaced at build time by `src/main/phonemizer-stub.ts`, which contains no eSpeak code. `scripts/check-licences.mjs` fails the build if eSpeak NG's code or data, or any GPL, AGPL, LGPL, non-commercial or unknown-licence package, is in the app.
- sharp and libvips (libvips is LGPL-3.0-or-later): replaced by `src/main/sharp-stub.ts`.

### Electron and Chromium
- Electron (MIT, Copyright Electron contributors) with Chromium (BSD-3-Clause and many others). Their licences are in `LICENSE.electron.txt` and `LICENSES.chromium.html` next to the app. These include LGPL-2.1 components that Chromium itself ships as separate libraries, notably FFmpeg (`ffmpeg.dll` on Windows, `libffmpeg.dylib` on Mac); MyBuildy does not change them. Chromium's credits list also quotes GPL and AGPL texts for components that are offered under more than one licence (for example JSZip, MIT or GPL-3.0); MyBuildy adds none of them.

## Used for training only (not shipped)
- Kokoro-82M voices (Apache License 2.0): synthetic "Hey Buildy", near-miss and general phrases.
- Piper voices (https://huggingface.co/rhasspy/piper-voices); only voices whose MODEL_CARD states a permissive dataset licence:
  - en_US-libritts_r-medium: LibriTTS-R, CC BY 4.0 (Koizumi et al., http://www.openslr.org/141/).
  - en_GB-vctk-medium: CSTR VCTK Corpus, CC BY 4.0 (Yamagishi, Veaux, MacDonald, University of Edinburgh, https://datashare.ed.ac.uk/handle/10283/3443).
  - Evaluation only: en_US-ljspeech-medium (LJ Speech, public domain) and en_GB-cori-medium (LibriVox, public domain).
  - Piper itself (GPL-3.0) was used only as a tool on a development machine to generate audio; no Piper code ships.
- LibriSpeech ASR corpus (dev-clean), CC BY 4.0: V. Panayotov, G. Chen, D. Povey, S. Khudanpur, "LibriSpeech: an ASR corpus based on public domain audio books", ICASSP 2015, https://www.openslr.org/12/. Used as negative (non-wake) training audio and for the false-trigger test.
- No output of online/cloud text-to-speech services was used for training.
